Model definition (high-ROI filter)

score = 0.40·|momentum| + 0.20·volume-surge + 0.20·visible-liquidity + 0.10·spread-tightness + 0.10·tradability

  • momentum — recent observed move normalized by the $0.10 alert threshold (capped at 1).
  • volume-surge — log-scaled 24-hour contract volume from the official market object.
  • visible-liquidity — top-of-book size from yes_bid_size_fp/yes_ask_size_fp (official fields).
  • spread-tightness — 1 − min(1, spread/$0.08).
  • tradability — penalizes contracts pinned near $0/$1 where nobody can exit.

A pick posts when score ≥ 0.62 and the fee-adjusted continuation estimate (entry at ask, target +50% of the recent move, taker fees on entry and exit) is ≥ 5% ROI. This is our heuristic computed over official prices — not an exchange product, and not financial advice.

Connecting a real demo account (optional, not active)

Kalshi's demo uses mock funds with credentials separate from production (official docs ↗). Real account/portfolio/order endpoints require demo API keys signed per request (RSA-PSS or Ed25519). This build deliberately does not include or request any credentials, so portfolio tracking here is the simulated engine above. If you later want live demo-account tracking, keys would be created by you in your own demo account and entered only in your own browser — never committed to this repository. This limitation is recorded on the Flagged for Review page.
