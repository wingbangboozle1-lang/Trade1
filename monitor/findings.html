Methodology & limitations (read before drawing conclusions)

  • Sample window. The monitor only observes while a page is open. Moves that happen while you are away are not in the archive (the exchange's official candlesticks/trades endpoints remain the source of truth).
  • Two independent signals. "Observed" = our consecutive polls; "exchange-reported" = the market's official previous_price_dollars vs last_price_dollars. Both must exceed the same threshold; both are labeled in the archive.
  • Attribution. We never assert why a price jumped. Alert entries include a news-search link labeled unverified context; confirming a cause requires reading the linked sources yourself.
  • Demo data quality. The demo environment is sparser than production: some topics (gas, culture) had zero open events at snapshot time, and some demo markets trade rarely. Empty tables are genuine exchange states, flagged on the Flagged page.
  • Dollar ranking. Estimated (volume × last price) because the API does not publish official per-event dollar volume; true traded dollars are computed from official trade prints only for the selected market's tape sample.

Suggested next steps for a trader

  • Keep the live dashboard open on a second screen; the watcher rotates the top events by estimated dollars every ~2.5 s.
  • Set the threshold to $0.05 for quiet periods (e.g. overnight) and back to $0.10 for busy sessions.
  • Check the tape and orderbook ladder before trusting any alert — thin books make small prints look like news.
  • Review strategy analytics after each session; close or disable strategies whose demo fills persistently underperform fees.
  • Read each market's official rules (linked in the event panel) before trading around resolution.
