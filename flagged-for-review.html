How the order book is represented

The selected-market table reports official bid price levels and contract quantities. Kalshi's order book returns YES and NO bids (not asks); the best bid is the highest-price, last entry in the ascending list. The dashboard shows a subset of the best levels. This is contract depth, not dollar depth or order counts.

Improvement suggestions

  • Use a small authenticated backend (never client-side private keys) for signed demo-account actions and secure WebSocket handling.
  • Persist all market ticks, settlements, paper fills, fees, and strategy versions in a database to enable reproducible backtests.
  • Paginate the full supported-market universe and add official event-category metadata rather than title-only keyword classification.
  • Build auditable event-source links with timestamps and source matching rules; keep price movement separate from causal claims.
  • Require explicit limits, position caps, kill switch, and paper-only mode before any separately authorized demo execution feature.
