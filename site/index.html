Executive summary (key points)

  • Environment: Kalshi demo exchange — separate from production, mock funds, prices may differ from real markets (official docs).
  • Data: public, unauthenticated REST endpoints (markets, events, series, orderbooks, trades, candlesticks) — no API key needed (official docs).
  • Resolution: YES result pays $1/contract to YES holders; NO result pays $1/contract to NO holders; no settlement fee (official docs). Watched markets show their YES/NO result automatically.
  • Simulated trading: paper engine executes Momentum, Mean-Reversion and Order-Book-Imbalance strategies on live demo quotes with the official taker fee roundup(M×0.07×C×P×(1−P)) (fee schedule PDF). Portfolio performance is tracked by strategy, topic and outcome.
  • Real demo-account trading requires a human-created demo account + API key; a read-only signed connector is included and order placement is intentionally dormant (F2/F11).
  • Full write-ups: verification methodology, flagged items, how to make this site even more live.
