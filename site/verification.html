✅ Verification methodology

Every fact in this project was checked against an official Kalshi source. Every table row on live pages links (a) the exact demo REST URL that produced its values and (b) the official Kalshi series page. Anything unverifiable is left blank and listed on the Flagged for Review page.

What "verified" means here

  1. Documentation-verified: the value/endpoint/parameter is stated in official docs that were fetched and read during this session (links below).
  2. Live-verified: the value was read directly from the official demo API host (external-api.demo.kalshi.co) during this session.
  3. Cross-checked: derived formulas (e.g., fees) reproduce the official published tables.
  4. Unverified: nothing else is shown. Blank cells + flag rows are the contract.

Fee-formula cross-check (engine vs official table)

Engine implements fee = roundup(0.07 × C × P × (1−P)) in dollars. The official general fee table (PDF) states 100 contracts at $0.50 → $1.75; at $0.05 → $0.34; at $0.10 → $0.63; at $0.25 → $1.32. The formula reproduces all four exactly (1.75, 0.3325→0.34, 0.63, 1.3125→1.32).
