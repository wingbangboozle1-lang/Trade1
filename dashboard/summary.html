Findings

  • Kalshi's demo environment is not a copy of production. Its open market list is dominated by freshly created multivariate combination markets with zero volume, so this dashboard reads live prices from the public production read endpoint and reserves the demo account for order execution. Both endpoints are Kalshi-documented; see Methodology.
  • Topic membership is checkable, not guessed. Market topics come from Kalshi's own series category/categories/tags fields and the published category→tag map, which is why "Culture" includes Entertainment and why "Golf" is a Sports tag.
  • "Highest dollar amount" is reported two honest ways: traded dollar volume and resting liquidity dollars. Kalshi publishes no single "money at stake" figure, so none is invented.
  • Sharp moves are detected, causes are not asserted. A ≥ $0.10 move is a fact from two observations; a news explanation needs a source, and unattributed moves stay labelled unverified.
  • Strategy results are simulated and reproducible. Six rule-based strategies trade the collected data with official fees and $1 settlement; the ledger is a committed JSON file, so any number on the Portfolio page can be re-derived.
  • The fee model is verified, not assumed. The engine's implementation reproduces all 21 published rows of Kalshi's fee schedule, and the test suite fails the build if it ever stops.

Limitations, stated plainly

  • No demo-account credentials exist in this environment, so live order execution has never run here. The code path is implemented, self-tested and refuses to fire without credentials.
  • Price history begins when the collector first ran. It is not exchange history; Kalshi's candlestick endpoint is used only for backfill when available.
  • Observation cadence is 15 minutes, so a move that reverses within the window can be missed.
  • Order-book depth is sampled for the largest markets per topic, not for every market, to stay inside Kalshi's rate limits.
  • News attribution is manual and empty by default. Unverified means unverified.
