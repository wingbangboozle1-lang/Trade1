Strategies

Six automated strategies, each a deterministic rule over the same collected data, so the comparison is fair. Every threshold below is the number actually used by the engine.

Deterministic by design. No randomness and no hand tuning between runs: the same snapshot always produces the same decision. That is what makes the results on the Portfolio page reproducible.

fair_value_vs_clock Statistical

With >= 3 days to close and the YES ask or bid at or below 0.45, compare price with a reference probability that rises linearly to 0.5 as close time approaches. Buy YES if reference - price >= 0.06; buy NO if price - reference >= 0.06.

Why these categories

  • Statistical — compares price with a reference probability that does not depend on the quote itself.
  • Momentum / Market making / Event driven — the three ways traders react to a move: follow it, fade it, or act on the news behind it.
  • Event thesis — category-level conviction rather than a price pattern.
  • Arbitrage — exploits the documented identity that a YES bid at X equals a NO ask at 1−X.
