KalshiDash

A live, interactive dashboard for the Kalshi demo API. Tracks the highest dollar-volume events across five topics — gas prices, elections, culture, crypto, and golf — until they resolve, runs automated simulated trades to test strategies, and tracks portfolio performance.

What this dashboard does

Live tracking & resolution

  • Highest dollar-volume events per topic, updated on a poll loop.
  • Events tracked until they resolve, with a clear yes / no outcome.
  • Interactive price chart: X = time (seconds / minutes / hours), Y = contract price.
  • Live orderbook — contracts available at each price (liquidity).
  • Sharp-move alerts for any price move ≥ $0.10, with links to the market.

Strategy & portfolio

  • Automated simulated (paper) trades testing momentum, mean-reversion, value, and liquidity strategies.
  • Trades categorized by strategy type and topic, with win-rate and P&L analysis.
  • Optional real demo execution with your Kalshi demo API credentials (stored only in your browser).
  • Live demo balance and open positions via signed API calls.

Executive summary

The Kalshi demo REST API (trade-api/v2) exposes public, unauthenticated market data (series, events, markets, orderbook, candlesticks) and authenticated portfolio/trading endpoints secured with RSA-PSS request signing. This dashboard consumes the public market-data endpoints directly from the browser for live prices and liquidity, and uses signed requests (WebCrypto RSA-PSS) for portfolio tracking and optional execution. A full write-up with source links is in docs/executive-summary.md.

Demo credentials (optional)

Public market data needs no credentials. To track your demo portfolio or execute real demo orders, provide a Kalshi demo API key ID and private key. These are kept in your browser session only and sent directly to Kalshi.
