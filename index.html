Demo & simulation only. This dashboard reads public Kalshi demo market data with no credentials and runs paper (simulated) trades in your browser. It does not connect to, fund, or place orders in a Kalshi account. Live account trading requires a demo API key, which is not requested or stored here.

Executive summary

Kalshi exposes a demo environment with mock funds and a separate Trade API rooted at https://external-api.demo.kalshi.co/trade-api/v2 (also https://demo-api.kalshi.co/trade-api/v2). Public market-data endpoints — GET /markets, GET /markets/{ticker}/orderbook, GET /events, GET /series — need no authentication and are readable from a browser, so this static dashboard can poll them live. WebSocket streaming is real-time but the handshake requires authentication, so this site uses public REST polling.

The dashboard tracks live markets in five topics — gas prices, elections, culture, crypto, golf — selected by a keyword heuristic on title/subtitle/ticker text (flagged: this is not an official category call). It ranks markets by the official volume_fp and shows a clearly-labeled derived dollar-volume estimate (volume × notional, not an official field). Every market row links to the official Kalshi market page.

A sampled price feed detects swings of ≥ $0.10 in either direction and writes them to two scrolling alert chats: all events and a high-ROI selective feed driven by a heuristic potential-return screen. A per-market chart plots YES price against time with selectable windows (seconds → hours), and the order book shows contracts available at each bid price. A paper strategy engine auto-places simulated trades (momentum, mean-reversion, value), settles them against the official result / settlement_value_dollars fields, and reports performance by strategy.

Scope limits are listed on the Flagged for Review page. Reference facts are verified against the official Kalshi docs on the Sources page.

Live & interactive — suggestions

  • Add a WebSocket mode behind a demo API key for sub-second ticks; until then REST polling at ~20s is the live transport.
  • Per-event sparklines in the market table (mini price strips) so trends are visible without opening the chart.
  • Alert sounds / browser notifications for ≥ $0.10 moves, with per-topic mute.
  • Historical candle overlay from GET /markets/candlesticks to compare the live line against recent OHLC.
  • Depth heat strip: color the order-book rows by contract size to spot thin liquidity at a price.
  • Cause-linking: for each ≥ $0.10 jump, surface a field to attach and verify a news/event link; cause is currently shown as unverified.
  • Watchlist persistence and export of alerts, positions, and settlement results to CSV for offline review.
