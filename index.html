Verification dashboard

A second, independent dashboard lives at dashboard/. It is generated every 15 minutes by a GitHub Actions pipeline from committed data files, so every number is reproducible from the repository rather than read live in your browser. Use it for: event rankings by traded dollar volume, per-topic tables, price charts with 1 min–7 day zoom, order-book liquidity, moves ≥ $0.10, resolved YES/NO outcomes, six simulated strategies with a paper portfolio, and a flagged-for-review page listing every unverified item with sources.

Kalshi Demo Monitor

Live, read-only view of Kalshi demo markets for gas prices, elections, culture, crypto and golf. Built from official Kalshi API documentation and endpoints.

Read this first. Kalshi’s demo environment is a separate test environment with its own markets, prices and play money. Demo prices are not production Kalshi prices. The site does not connect to any account, place orders, or prove why prices moved.

Executive summary

  • What it does: lists open markets in five topics, charts recent official trade prints, shows resting bid liquidity by price, flags swings of $0.10 or more within 5 minutes, and tracks simulated strategies and resolved outcomes.
  • Where data comes from: the official Kalshi Trade API (demo base external-api.demo.kalshi.co/trade-api/v2, documented at API environments). Every table row links to its own API endpoint.
  • Ranking: by open interest × notional value (a derived dollar figure) or by contracts traded (official volume). Kalshi does not publish a per-event dollar-volume field, so no official “dollar amount” ranking exists here.
  • Causes of moves: not verified. Alerts link to Kalshi’s official settlement sources for the event as context only.
  • Not done: demo-account portfolio tracking and order execution need demo API credentials, which were not provided. No trades were placed on Kalshi. Simulated trades are only in this browser.
  • Open items: see Flagged for Review (keyword topic rules, demo-vs-production data, unverified browser access to the API, CORS, and repo findings).
