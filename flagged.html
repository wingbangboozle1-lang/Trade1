irregularity Kalshi's Culture category is nearly emptyculture-category-gap The live API returns only two series under category=Culture, so this dashboard defines Culture as Culture + Entertainment + Social. Awards, music, TV and movie markets live under Entertainment; the mapping is shown on each page that uses it. Culture numbers are broader than the literal category name. source
irregularity Demo market data is not representativedemo-not-production Kalshi states demo markets 'may not be reflective of those in real markets'. A probe of the demo endpoint returned 200 open markets of which 193 were multivariate combination markets with zero volume. Live prices therefore come from the public production read endpoint; the demo environment is reserved for order execution. Rankings reflect production markets, while executions target demo markets. source
unverified Causes of ≥ $0.10 moves are unattributedjump-causes-unattributed Moves are detected from exchange prices. Naming a news cause would be a claim needing a source, so every move is labelled unverified until a reviewer files a source URL in data/attributions.json. The sharp-move page shows facts and links, not explanations. source
unverified Live push (WebSocket) not enabledno-websocket-without-keys Kalshi's WebSocket requires an authenticated handshake even for public market-data channels, so a signature needs credentials. The site polls REST every 15 minutes instead. This is a documented API constraint, not an omission. Updates are as fresh as the last pipeline run (timestamp shown on every page). source source
note Per-series fee multipliers are only partly transcribedfees-series-table-partial Kalshi's fee schedule lists per-series multipliers in a table whose PDF text layer is partly garbled. Only rows that could be read unambiguously are encoded; all other series use the schedule defaults (taker M=1, maker M=0). Series with a non-standard multiplier outside that subset would be fee-mispriced in simulation. Simulated fees may differ from exchange fees for unusual series. source
note One editorial rule in the gas topicgas-title-rule Gas-price membership requires a Kalshi 'Oil and energy' / 'Oil & Gas' tag AND the word 'gas' in the series title. Without the title test, oil-inventory series would be counted as gasoline price markets. This is the only editorial test in the topic config and it is declared here rather than hidden in code. Possibly excludes a gas series whose title omits the word 'gas'. source source
note Price history begins with the first collector runhistory-starts-now Chart series are built from observations this repo has collected. They are not exchange history and are not back-filled; the candlestick endpoint is used only where a real exchange history exists for the requested window. Charts get richer over time; early windows can be sparse. source
note No single 'total money at stake' figure existsno-money-at-stake Kalshi's public API exposes per-market volume and open interest, not a committed capital pool. The dashboard reports traded dollar volume, open-interest dollars and resting liquidity instead, and never presents a made-up aggregate. Rankings use traded dollars, which can differ from capital currently at risk. source

How to clear an item

  1. Provide the missing input (for example demo API credentials), or
  2. file a source URL that settles the question in data/attributions.json or the corresponding data file, then
  3. re-run the pipeline; the item disappears from data/flagged.json on the next build.
