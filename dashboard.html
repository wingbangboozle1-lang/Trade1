Suggestions — making the site more live and interactive

  • Replace polling with the demo WebSocket (wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2 or wss://demo-api.kalshi.co/trade-api/ws/v2) for push price ticks instead of 5-second polling.
  • Browser notifications on ≥ $0.10 swings so alerts surface without the tab in focus.
  • Persistent alert history server-side or indexed by event ticker, not only in this session.
  • Overlay cause links: when a sharp move coincides with a published news event, show the source link next to the alert (cause attribution must be verified per event).
  • Multi-market mini-sparklines on each row so movement is visible without opening the chart.
  • Authenticate the demo account (Kalshi requires private-key signed requests) to track real positions, settlement history, and P&L — never store credentials in the browser.
